PROBLEM SOLVING

운영 중 마주친 문제를 확인하고 수정한 사례

01

모바일 레이아웃 깨짐

문제: 특정 해상도에서 이미지와 텍스트가 겹침

해결: breakpoint와 이미지 비율을 조정해 모바일 흐름 안정화

02

메인 영상 초기 로딩

문제: 진입 시 영상 영역이 늦게 표시됨

해결: poster와 대체 배경을 적용해 첫 화면 표시 품질 개선

03

잘못된 URL 이동

문제: 기존 링크가 의도하지 않은 페이지로 연결됨

해결: URL 구조와 리다이렉트 흐름을 확인하고 필요한 링크 수정

04

Search Console 색인 점검

문제: 일부 페이지가 검색 결과에 안정적으로 노출되지 않음

해결: 색인 상태, sitemap, URL 상태를 확인하고 개선 사항 반영

05

게시판 목록 개선

문제: 게시글 목록 흐름과 UI 가독성이 부족함

해결: 목록 간격, 버튼, 모바일 정렬을 조정해 운영 화면 개선

06

공공데이터 오류 확인

문제: 기관 데이터와 화면 표시값이 맞지 않는 항목 발생

해결: 원본 데이터와 기존 코드를 확인하고 필요한 수정 적용
