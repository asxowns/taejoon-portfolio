PROBLEM SOLVING

실제 운영 중 마주친 문제를 확인하고 수정한 사례

01

모바일 반응형 레이아웃

문제: 특정 해상도에서 이미지와 텍스트가 겹치거나 여백이 무너짐

해결: breakpoint, width, 이미지 비율을 조정해 모바일 흐름 안정화

02

기존 UI 수정

문제: 기존 페이지의 버튼, 목록, 섹션 간격이 화면 크기별로 어색함

해결: CSS 정렬과 여백을 조정하고 PC·모바일 화면에서 재확인

03

서버 반영 및 테스트

문제: 로컬 수정과 실제 서버 화면이 다르게 보일 수 있음

해결: 수정 파일을 서버에 반영한 뒤 브라우저와 기기 폭을 바꿔 확인

04

Search Console 점검

문제: 일부 페이지의 검색 노출과 색인 상태 확인이 필요함

해결: Search Console에서 색인, sitemap, URL 상태를 확인하고 개선 사항 반영

05

콘텐츠·게시판 운영

문제: 게시글 목록 흐름과 콘텐츠 표시 방식의 가독성이 부족함

해결: 목록 간격, 버튼, 모바일 정렬을 조정하고 필요한 콘텐츠 반영

06

데이터 표시 오류 확인

문제: 기관 데이터와 화면 표시값이 맞지 않는 항목 발생

해결: MySQL 데이터 조회와 AI 도구를 활용한 기존 코드 분석 후 수정 적용
